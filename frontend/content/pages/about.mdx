Hello, I'm Saiem. I work as a machine learning engineer, computer vision by trade, and I have spent most of my
evenings since 2020 making public sports data easier to get at. That work grew into the
[SportsDataverse](https://sportsdataverse.org "The home page of the SportsDataverse Organization"): a set of R,
Python and JavaScript packages that share the same ideas about tidy data, the same release pipeline, and, where it
matters, the same models.

## What I'm building now

- **The packages.** Fourteen public libraries carry my name in their metadata; the list is below and on the
  [work page](/work), and each one has a [note](/notes) written from its own description. In 2026 the R side
  finished a long CRAN campaign — cfbfastR, hoopR, wehoop, fastRhockey, baseballr, oddsapiR and cfbseedR are all
  on CRAN — and the Python package was rebuilt end to end on polars.
- **The data.** Every `load_*()` function reads from automated release repositories
  ([sportsdataverse-data](https://github.com/sportsdataverse/sportsdataverse-data) and its per-sport siblings): play
  by play, box scores, schedules, rosters and, increasingly, fitted models — expected points, win probability,
  shot quality, expected goals — with the training code committed beside the data.
- **[Game on Paper](https://gameonpaper.com/cfb "Game on Paper: live analytics for the modern age").** Live
  college football analytics, built on the JavaScript package and the same models.
- **This site's [lab](/lab).** Small, runnable ideas: querying a release file from the browser with DuckDB, a series
  odds calculator that runs on the server, and a metered question-and-answer over the lab's own data sources.

## R packages

Author and maintainer unless noted.

- [cfbfastR](https://cfbfastR.sportsdataverse.org/) — college football play by play, EPA and win probability
  ([source](https://github.com/sportsdataverse/cfbfastR), [data](https://github.com/sportsdataverse/cfbfastR-data))
- [hoopR](https://hoopR.sportsdataverse.org/) — men's basketball: ESPN, the NBA Stats API and KenPom
  ([source](https://github.com/sportsdataverse/hoopR), [data](https://github.com/sportsdataverse/hoopR-data))
- [wehoop](https://wehoop.sportsdataverse.org/) — women's basketball: ESPN and the WNBA Stats API
  ([source](https://github.com/sportsdataverse/wehoop), [data](https://github.com/sportsdataverse/wehoop-data))
- [fastRhockey](https://fastRhockey.sportsdataverse.org/) — NHL, PWHL and the HockeyTech leagues
  ([source](https://github.com/sportsdataverse/fastRhockey), [data](https://github.com/sportsdataverse/fastRhockey-data))
- [baseballr](https://billpetti.github.io/baseballr/) — Bill Petti's baseball package; I maintain it
  ([source](https://github.com/BillPetti/baseballr), [data](https://github.com/sportsdataverse/baseballr-data))
- [oddsapiR](https://oddsapir.sportsdataverse.org/) — sports odds from The Odds API
  ([source](https://github.com/sportsdataverse/oddsapiR))
- [cfbseedR](https://cfbseedR.sportsdataverse.org/) — college football season simulation and playoff seeding
  ([source](https://github.com/sportsdataverse/cfbseedR))
- [cfb4th](https://cfb4th.sportsdataverse.org/) — fourth-down decisions ([source](https://github.com/sportsdataverse/cfb4th))
- [cfbplotR](https://cfbplotr.sportsdataverse.org/) and [sdvplotR](https://sdvplotr.sportsdataverse.org/) — logos, colors
  and themes for ggplot2, gt and reactable ([cfbplotR source](https://github.com/sportsdataverse/cfbplotR),
  [sdvplotR source](https://github.com/sportsdataverse/sdvplotR))
- [recruitR](https://recruitr.sportsdataverse.org/) — college recruiting rankings ([source](https://github.com/sportsdataverse/recruitR))
- [usfootballR](https://usfootballr.sportsdataverse.org/) — MLS and NWSL from ESPN ([source](https://github.com/sportsdataverse/usfootballR))
- [sportsdataverse](https://r.sportsdataverse.org/) — the meta-package that installs and loads the family
  ([source](https://github.com/sportsdataverse/sportsdataverse-R)), and
  [sportsdataversedata](https://github.com/sportsdataverse/sportsdataverse-data), the release plumbing behind the loaders

## Python

- [sportsdataverse](https://py.sportsdataverse.org/) — ESPN across every league, the NBA and WNBA stats APIs, NHL,
