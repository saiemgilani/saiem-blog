At [saiemgilani.com](https://www.saiemgilani.com), I do not collect personal information. There are no accounts, no forms, no newsletter sign-up and no cookies set by this site.

**Analytics.** I use [Plausible](https://plausible.io/data-policy), a privacy-focused service that counts page views without cookies or cross-site tracking and does not store IP addresses or any identifier that could single out a visitor. I use these aggregate numbers only to see which pages people read.

**The lab.** Interactive entries under `/lab` run in your browser. When one of them reads a public SportsDataverse data file, the request passes through this site so your browser can read it; that request is not logged against you. A per-IP rate limit protects the relay from abuse.

**Third parties.** The site is hosted on Vercel and loads some assets from GitHub and jsDelivr; each has its own privacy practices. Nothing collected here is shared with anyone, except as required by law.

I may update this policy from time to time; changes are posted here.

If you have any questions or concerns about the Privacy Policy, please contact me at [saiem.gilani@gmail.com](mailto:saiem.gilani@gmail.com).
