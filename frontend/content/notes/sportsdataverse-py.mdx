**sportsdataverse (Python)** is a Python package. The Python side of the house, rebuilt on polars: ESPN across every league, the NBA and WNBA stats APIs, NHL, MLB and Statcast, HockeyTech, stats.ncaa.org, and the same loaders and models the R packages ship.

Retrieve Sports data in Python

## Install

```bash
pip install sportsdataverse
uv add sportsdataverse
```
