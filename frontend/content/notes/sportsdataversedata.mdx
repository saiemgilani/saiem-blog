**sportsdataversedata** is an R package. This repository holds automated data releases for sportsdataverse projects and helper functions for managing the uploads.

The release plumbing behind every `load_*()` function: publish a data frame to a GitHub release in several formats, read it back, and keep the timestamps honest. Ported to Python in sportsdataverse-py as `sportsdataverse.release`.

## Install

```r
pak::pak("sportsdataverse/sportsdataverse-data")
```

Not on CRAN — install from GitHub with pak (or remotes).
