**baseballr** is an R package. Provides numerous utilities for acquiring and analyzing baseball data from online sources such as 'Baseball Reference' https://www.baseball-reference.com/, 'FanGraphs' https://www.fangraphs.com/, and the 'MLB Stats' API https://www.mlb.com/.

Bill Petti's package is the one most R baseball people learned on. I took over maintenance and brought it onto CRAN alongside the rest of the family.

## Install

```r
install.packages("baseballr")
pak::pak("BillPetti/baseballr")
```

On CRAN (v2.0.0); the second line installs the development version.
