**recruitR** is an R package. As a college sports recruiting package, recruitR provides users with the access to 247 Composite rankings and recruit information from the CollegeFootballData API.

The first SportsDataverse package I wrote, in 2020: recruiting rankings and team classes from the 247 Composite via the CollegeFootballData API.

## Install

```r
pak::pak("sportsdataverse/recruitR")
```

Not on CRAN — install from GitHub with pak (or remotes).
