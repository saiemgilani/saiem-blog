**cfb4th** is an R package. A set of functions to estimate outcomes of fourth down plays in NCAA football and obtain fourth down plays from https://www.espn.com/.

Fourth-down decision estimates for college football in the spirit of nfl4th, built on cfbfastR's play data.

## Install

```r
pak::pak("sportsdataverse/cfb4th")
```

Not on CRAN — install from GitHub with pak (or remotes).
