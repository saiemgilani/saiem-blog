**usfootballR** is an R package. A utility for working with American soccer data. A scraping and aggregating interface for ESPN's https://www.espn.com MLS and NWSL statistics.

American soccer, the football that is called soccer here: MLS and NWSL play-by-play and statistics from ESPN.

## Install

```r
pak::pak("sportsdataverse/usfootballR")
```

Not on CRAN — install from GitHub with pak (or remotes).
