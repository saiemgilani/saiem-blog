**cfbplotR** is an R package. A set of functions to visualize College Football analysis in 'ggplot2'.

Team logos, colors and headshots as ggplot2 geoms and scales, so a college football chart looks like one without a manual asset hunt.

## Install

```r
pak::pak("sportsdataverse/cfbplotR")
```

Not on CRAN — install from GitHub with pak (or remotes).
