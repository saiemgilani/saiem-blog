**wehoop** is an R package. A utility for working with women's basketball data. A scraping and aggregating interface for the WNBA Stats API https://stats.wnba.com/ and ESPN's https://www.espn.com women's college basketball and WNBA statistics. It provides users with the capability to access the game play-by-plays, box scores, standings and results to analyze the data for themselves.

The women's-game sibling of hoopR: ESPN and WNBA Stats API access, plus the same win-probability columns the men's data carries.

## Install

```r
install.packages("wehoop")
pak::pak("sportsdataverse/wehoop")
```

On CRAN (v3.0.0); the second line installs the development version.
