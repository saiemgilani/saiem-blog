**fastRhockey** is an R package for hockey data: play-by-play and statistics for the Professional Women's Hockey League (PWHL), which began play in 2023–24 after the Premier Hockey Federation (PHF, formerly the National Women's Hockey League) folded, plus the National Hockey League's stats API. The older PHF endpoints remain for the seasons that league played.

Started for the PHF, grew into the NHL stats API and, more recently, the PWHL and the HockeyTech family of minor and junior leagues.

## Install

```r
install.packages("fastRhockey")
pak::pak("sportsdataverse/fastRhockey")
```

On CRAN (v1.0.0); the second line installs the development version.
