**fastRhockey** is an R package. A utility to scrape and load play-by-play data and statistics from the Professional Women's Hockey League https://www.thepwhl.com/, formerly known as the Premier Hockey Federation (PHF) or National Women's Hockey League (NWHL). Additionally, allows access to the National Hockey League's stats API https://www.nhl.com/.

Started for the PHF, grew into the NHL stats API and, more recently, the PWHL and the HockeyTech family of minor and junior leagues.

## Install

```r
install.packages("fastRhockey")
pak::pak("sportsdataverse/fastRhockey")
```

On CRAN (v1.0.0); the second line installs the development version.
